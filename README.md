# Insurance Risk Factor Analysis

## Multivariate Analysis of Common and Unique Factors

This repository contains a statistical analysis of **common and unique factors** using multivariate statistical methods.

The project was initially developed as part of my work in the **Master's in Statistics at Universidad Nacional de Colombia**. I am now organizing and extending the analysis so that it can be reproduced and presented as part of my data science and statistical modeling portfolio.

## What is this project about?

When several variables are related to each other, it is possible that part of their variability comes from a smaller number of underlying factors.

Factor analysis provides a way to study this structure by separating:

* variability shared between variables;
* variability specific to each variable;
* and the contribution of the common factors.

The basic model considered in this project is

$$
X = \mu + \Lambda F + U
$$

where \(F\) represents the common factors and \(U\) represents the unique part of each variable.

## Analysis

The project includes the following topics:

* Exploratory data analysis
* Correlation structure
* Multivariate analysis
* Common and unique factors
* Communalities
* Factor estimation
* Maximum likelihood estimation
* Selection of the number of factors
* Factor rotation
* Varimax rotation
* KMO measure
* Interpretation of the resulting factors

One of the main goals is not only to obtain the factors, but also to understand what they represent and how well they describe the original variables.

## Data and methodology

The analysis is developed using **R** and follows the statistical methodology studied during my Master's program.

The workflow will be organized progressively, starting with the original academic analysis and then adding improvements in data exploration, visualization, reproducibility and interpretation.

## Insurance Risk Application

An additional objective of this project is to explore how multivariate statistical techniques can be used in **insurance risk analytics**.

In later stages, the latent factors will be connected with statistical models such as **Generalized Linear Models (GLMs)** to study their potential use in risk modeling.

This part of the project is still under development.
